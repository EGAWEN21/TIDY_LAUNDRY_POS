# TidyPOS Consolidated Implementation Tracker\n\nCreated: 2026-09-13  \nLast updated: 2026-09-13  \nOverall status: **Phase 0 / Batch 1 in progress**\n\nThis directory tracks the approved **TidyPOS reliability, security, and complete Vue POS replacement plan**. This is a hardening project—not a system rewrite. Laravel actions and DTOs, the Livewire back office, Vue offline POS, Sanctum, Pinia, Dexie, and IndexedDB remain the foundation.\n\n## Priority\n\n**Protect saved work → enforce permissions and financial rules → make synchronization predictable → replace legacy POS workflows → remove obsolete code safely.**\n\n## Final architecture\n\n| Surface | Final responsibility |\n|---|---|\n| Vue `/admin/pos` | Offline-capable order creation |\n| Vue `/admin/pos/edit/{id}` | Online-only existing-order editing |\n| Vue `/admin/orders/requests/edit/{id}` | Online-only order-request editing |\n| Livewire back office | Orders, customers, reports, settings, approvals, and administration |\n| Laravel actions/services | Authoritative business rules and persistence |\n| Sanctum APIs | Authorized creation synchronization and online editing |\n| IndexedDB | Creation drafts, catalog data, and offline creation queue |\n\nVue replaces the Livewire POS only—not the entire Livewire back office.\n\n## Authority\n\nThis tracker records the consolidated plan approved on 2026-09-13. It supersedes older final-architecture statements in `docs/engineering-roadmap.md` and `docs/browser-acceptance-checklist.md` where those documents describe `/admin/online-pos` and `/admin/pos` as permanently separate POS implementations. Those documents remain historical evidence until deliberately revised.\n\n## Status legend\n\n- `[ ]` Not started or not verified\n- `[~]` In progress or partially verified\n- `[x]` Complete with evidence\n- `[!]` Blocked or requires an explicit decision\n\nA phase is complete only when all required work, tests, and its completion gate pass.
